# Diseño responsivo

Este proyecto es un sistema web que se usará en computadora, tablet y celular. Todo el código de UI debe ser responsivo y verse bien en los tres tipos de dispositivos. Usar breakpoints mobile-first con Tailwind (sm, md, lg) o equivalentes CSS. Probar mentalmente los layouts en pantallas pequeñas antes de considerar una tarea terminada.
